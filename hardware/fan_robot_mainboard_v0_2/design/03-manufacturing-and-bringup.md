# 工厂制造与首板验收 V0.2

## 投板/装配

以 fabrication/FABRICATION_NOTES.txt 为制造参数；先少量工程打样（建议 5 块），工厂报价/最小起订量为准。上传 PCB_Gerber_V0.2.zip，双面 SMT 导入 BOM_JLC_SMT.csv + CPL_JLC.csv；J1～J5 插件另按 BOM_JLC_THT.csv 报价。C10、J7、J8 不装；测试点是铜焊盘，无需器件。stencil 下是双面焊膏 Gerber，不混作 PCB 铜层。

坐标全部由实际 PCB 导出；CPL 原点在板左下，+X 右/+Y 上，底面 X 没有取负。Gerber/钻孔使用同一 (0,50mm) KiCad 辅助原点。Gerber 铜层和钻孔不要镜像；仅 bottom 装配图为从背面观察的镜像视图。安装孔中心在左下坐标 (3,3)、(57,3)、(3,47)、(57,47)，孔径 2.7mm NPTH。

工厂按装配图与 orientation-register.json 的实际 1 脚位置复核 CPL 角度；物料库零度方向可能不同，坐标导入后需要正常贴装工程校正。重点 U1/U2/U3/U4/U5/U8、Q1～Q3、D1～D3、C1 与 J6。C1 pad1 正极；D1～D3 pad1 阴极；J1 pad1 BAT+；J4 pad1 FAN_5V，pad2 是开关回路而非地。接头无料时，不允许只按“2P”自动换成另一种针距。

焊接要求：先按双面回流工艺排程，重器件防掉落，THT 后焊；U2 特殊 DLA0010A 焊盘不能替换通用 DFN+EP，DRV PowerPAD 必须焊接，ESP32 模组依原厂推荐热盘工艺。常规过孔双面盖油，散热孔焊膏避让；若工厂判定需塞孔/填孔或钢网调整，由工程反馈具体 DFM 修改，不随意修改导通铜。建议 0.10mm 钢网起评估，最终开口/回流窗口结合模组、聚合物电容及工厂工艺，包含 AOI、连锡检查和裸板电测。裸板无固件，不要求工厂自动运行电机。

## 断电检查

1. 对照 BOM/装配图检查 81 个安装器件、3 个不装位、极性/1脚、锡桥、热盘与插座方向。
2. 万用表检查电池正负、VBAT/GND、3V3/GND、FAN_5V/GND 无意外短路；检查 1M/330k、68.1k、0.39Ω 料值，排除漏装和错阻值。
3. 用接口表逐针核对相机插合关系，特别 GND/3V3 与左右镜像。先不接相机、电机、风扇和干电池。不能只看 2.54mm 间距就带电盲插。

## 限流首上电

1. J1 接可调限流电源，4.5V。SW1 OFF，电流限制先 100mA，只检查关断/漏电；ON 后主控可能因限流启动受阻，确认无异常后提高至 300～500mA 做无外设逻辑检查，不能把限流反复重启当成电源电路故障或据此提高到任意大电流。
2. 测 TP2 VBAT、TP3 3V3、TP10 ESP_EN。3V3 静态验收初始范围 3.20～3.40V；纹波/瞬态另测，USB 和电池分别测试。TP5 ACT_REQ、TP6 ACT_EN 应为低，电机不驱动，Q1 风扇开关关闭。升压 EN 低不等于输出节点必为 0V，需结合芯片关断电流路径判断。
3. 确认电池关闭时 USB 不倒灌 BAT_RAW，电池供电时不倒灌 USB VBUS；USB 单独供电负载不能超出限流预算。反接验证用限流实验电源和受控步骤，禁止拿大电流电池直接试短路。
4. 插 USB、按 BOOT 后复位，验证 USB 下载。复位/下载/拔插全过程用示波器观察 ACT_EN 与电机输出，所有未启用时段不得驱动。网页或日志不能替代输出电平测量。

## 固件与功能验收（新板固件移植后）

1. 使用独立 mainboard_v0_2 配置，GPIO15/2 左电机、38/39 右电机、GPIO40 风扇、GPIO47 使能、GPIO42 故障、GPIO1 ADC1。现有固件未提供可直接烧入此板的版本；先完成接口文档中的移植要求。
2. 先只接相机，读取真实 PID/板号/时钟；照片为 OV5640 丝印、工作配置为 OV2640，若不一致先适配驱动，再验证帧率、倒装翻转、USB/Wi-Fi 同时工作和 PSRAM。不得通过删除 PID 错误检查来掩盖配置差异。
3. 接单路电机并固定车体/悬空履带，分辨极性和 A/B 方向；测真实启动、连续、短时受控堵转/限流电流，核对 nFAULT 和故障锁存。名义 0.513A 不代表实际电机必能起转。需要调整限流时，重新核对驱动/电池/接口温升后再改 RS 值，不能短接采样电阻。
4. 再接另一台电机与风扇，测 FAN_5V（目标约 4.95～5.0V，静态初始范围 4.75～5.25V）、启动电流与关断尖峰。没有测速输入，网页只能显示风扇命令/保持状态。
5. 实际三节同型号新干电池和低电量电池各测：75% PWM、700ms 前后脉冲/100ms 间隔、转向、相机+Wi-Fi+风扇并发、USB 热插拔、目标丢失和相机帧过期。记录 VBAT/3V3 瞬态、误复位和低电压停机迟滞。USB 接着时不要让逻辑供电掩盖电池耗尽。
6. 台架逐步增加负载、观察 1/5/10 分钟温升；首轮以可触及外壳/器件表面约 60°C 为保守暂停线，并结合环境温度和芯片结温估算重新评审，不能把表面温度直接当结温。记录 U2/U3/U4、Q2/Q3、L1/L2、二极管、RS1/RS2、F1、接头及电池盒温升。
7. GPIO42 故障、WDT、相机失败、配置错误、刷写/复位均应撤销使能；避免自动无休止重试。执行器不受控时切断电池。通过后再在远离桌边的受控区域验证手部居中、距离调节与风扇联动。

## 机械与无线

四孔 M2.5 尼龙紧固件/绝缘垫柱，背面有按键和元件，预留至少 5mm 支撑高度并核对实际底部净空；不要压到 USB 壳体/焊点。相机如直接插合需实物核对高度和周围器件，不能由针距推定整机无干涉。需要线束时按接口逐针制作并保持短线，图像稳定性需测，未验证任意长度并口延长。

天线在板上边，x6～54mm、距上边6mm区域全层禁铜；装壳后不要被电池、金属履带/螺柱或导电外壳包围，按乐鑫指南维持天线周围净空并测试真实姿态的 Wi-Fi 信号/吞吐。

完成测试记录后才扩大生产；首板可投并不代表供电余量、温升、RF、EMC、寿命和整机安全已经实测合格。
