# 电气设计要求

## 1. 冻结的用户要求

- 新板为专用主板，不插载现有 ESP32 开发板、DRV8833 模块或 LR7843 模块。
- 采用 ESP32-S3-WROOM-1-N16R8 焊接模组，保留已跑通的 16MB Flash / 8MB Octal PSRAM 能力；不做裸 SoC 射频设计。
- 使用三节 1.5V 干电池串联，不采用锂电池，不配置充电器。USB 不得给干电池充电。
- PCB 目标 60×50mm，四层，结构与孔位尚未冻结。
- 相机继续外接，用户确认主板接口为2×9针，同排节距与两排中心距均2.54mm，图纸板宽24mm；不把24pin镜头FPC当成主板接口。沿用已跑通BY-OV2640-V1.5/板载24MHz配置，新提供照片丝印为OV5640，与历史确认不一致，最终以现有实物PID及板号核实；不能只凭同样排针就承诺传感器可互换。
- 两台N20电机，用户确认标称6V、60转/分钟；起动/堵转电流与转速测试条件尚无参数。
- 保留当前手部识别、自动启动、75% PWM、动作时限与风扇 30 秒滑动续转的产品目标，但新板需要固件移植后才能执行。

## 2. 电源方案

电池 → SW1 → F1 → Q2 反接保护 → VBAT。

- VBAT 直接供 U4 DRV8833 电机桥，PWM 不改变电池电压，不声称是恒压调速。
- VBAT 与 USB VBUS 各经一只隔离二极管 D2/D3 汇到 VLOGIC_IN，仅供 U2 TPS63802 升降压生成 3.3V，供主控与相机。
- VBAT 单独供 U3 TPS61023 升压至约 5.0V，供两线风扇。U3 只在硬件执行器使能有效时开启。
- USB 不接电机/风扇电源；拔掉电池只保留 USB 时，不允许驱动负载。二极管 OR 不等于充电管理或精密电源选择器；需要验证漏电、热、掉压和插拔瞬态。
- 不建议直接把电池经 LDO 当作全范围 3.3V 电源，也不直接让 5V 风扇跟随电池电压下降。
- U2 3.3V 使用 560k/100k 反馈。U3 使用 732k/100k，PWM 参考值下约 4.95V，PFM 约 5.0V，最终以容差/瞬态验证为准。
- U2 MODE=低（节能模式）。EN 分压180k/100k对应 VLOGIC_IN 上升约3.08V、下降约2.80V，不等于原始电池阈值；必须结合二极管压降与容差确认电池耗尽行为。
- U2 PG 接 ESP_EN，由10k上拉与1uF建立复位延时，RESET 按键可拉低。验证 PG 开漏启动时序，不能仅凭连接表认为复位已合格。

### 负载预算与干电池限制

首版验证目标（不是实测额定值）：3.3V 平均 0.5A、峰值 0.8A；风扇额定 0.1A@5V，启动电流待测；每路电机电流斩波候选约0.51A，不能把它当成电机实际工作/堵转电流。

在 VBAT=3.0V、转换效率保守按85%、主控峰值0.8A、风扇0.1A以及两路电机各0.51A估算，电池瞬时电流可超过2.2A；三节干电池是否承受得住并未验证。必须实测电池内阻、触点压降、两路电机启动与 Wi-Fi/相机同时运行时的掉压。不能以“电源芯片标称2A”证明电池供电稳定或续航。三个电芯需同型号同状态，不混装；板上不充电。若测试失败，回到电源/限流设计，不自动扩大电流或取消保护。

USB 支路只用于下载/调试与主控电源，不给负载供电。没有 USB PD，也没有大电流 USB-C 协商控制器；5.1k CC 下拉不授权任意取流。最终应评估电脑 USB 枚举前后和运行峰值电流预算；首板调试不能直接假定任意电脑端口可稳定供给 0.8A。

## 3. 电机驱动

继续使用已跑通的三节干电池直接驱动，不增加6V升压支路。6V是电机标称电压，三节电池标称4.5V并会随负载和电量下降；75% PWM、桥路压降、负载与限流还会影响速度/起动力矩。不得据60转/分钟标签保证本机速度，也不把PWM等效平均电压当作恒压电源。新板需在实际低电量和履带负载下验证可靠起转；失败时重新评估限流/驱动/减速比或电源，而非直接提高PWM或取消保护。

U4 使用 DRV8833PWPR（HTSSOP-16，带 PowerPAD），不是普通 TSSOP PW，也不是不同针脚顺序的 WQFN 版本。电源、VCP、VINT 去耦按数据手册拓扑。

- GPIO1/2 → AIN1/2；GPIO38/39 → BIN1/2。外部四路10k下拉。
- AOUT1/AOUT2 接左履带 N20 两端；BOUT1/BOUT2 接右履带两端。
- AISEN/BISEN 各经候选0.39Ω/0.5W/1%电阻回地，名义 Itrip=0.2/0.39≈0.513A。起转、持续力矩、斩波噪声、比较器容差、散热和电阻温升未验收；不得不测电流就把采样电阻短接。
- nFAULT 为开漏，上拉到3.3V后接GPIO42。不能上拉到电池/5V。
- 电机回流与开关电源回流以布局路径控制，不能穿越相机/主控敏感地线；整板用连续地平面，不随意切割地面。

## 4. 上电/复位/刷写默认禁能

此项对应实物刷写时右轮自转的问题，属于新主板必须验收的功能。

- GPIO47 为 ACT_REQ，外部10k下拉，不选择曾异常的GPIO39、40作为唯一使能。
- U6 与门：ACT_EN = ACT_REQ AND ESP_EN；ACT_EN 另有10k下拉。
- ACT_EN 控制 DRV8833 nSLEEP，并控制风扇升压 EN。
- U7 与门：FAN_GATE_LOGIC = FAN_CMD(GPIO40) AND ACT_EN；经100Ω驱动Q1栅极，栅源100k下拉。
- GPIO47未被程序主动置高时，电机与风扇默认关闭；EN拉低时也应立即关闭。复位/下载期间需要示波器测量 ACT_EN 和电机输出，不能仅看网页或软件状态。
- 该电路不是独立于软件的安全认证或硬件看门狗。程序若卡死且 GPIO47 维持高，仍需软件看门狗与物理电源开关；不宣称可防止所有失效。

## 5. 风扇

U3 提供5V，Q1 AO3400A低侧开关。风扇红线接 FAN_5V，黑线接 FAN_SW，不能直接接GND绕过开关。候选D1跨接端子，阴极接5V，阳极接FAN_SW；验证具体两线无刷风扇的关断与瞬态，不把它建模成裸有刷电机。没有转速反馈，网页只能报告开关输出。

## 6. 主控、USB 与扩展

ESP32-S3-WROOM-1-N16R8 的GPIO35/36/37因Octal PSRAM留空，禁止复用。全部地脚与41号EPAD按模块指南接地。BOOT0采用10k上拉及按键，保留GPIO45/46/3默认状态，不外接改变启动配置的负载。

USB-C USB2.0采用双5.1k CC下拉、USBLC6-2SC6保护、D+/D−串联22Ω至GPIO20/19。ESD靠近接口，USB差分阻抗由实际叠层/板厂计算并按芯片指南处理。USB接头的完整订货号未冻结，不把SH信号直接当作实际全部机械焊盘号。

GPIO41/48提供3.3V I2C扩展，便于未来ToF/IMU。GPIO15预留电池分压ADC，100nF滤波；这是ADC2，必须验证在Wi-Fi运行时的采集支持和错误处理，不能未经测试作为唯一欠压保护。GPIO43/44保留UART测试口。

## 7. PCB 布局要求（待实际布板）

- 目标60×50mm，4层；建议 L1器件/信号、L2完整GND、L3电源/低速、L4辅助信号/GND。叠层、铜厚由板厂和电流预算冻结。
- 模组天线放板边或外伸，按乐鑫官方全层禁布/金属间距要求留空，不能被电池、履带金属、螺柱或外壳导电层遮挡。结构草图不替代最终RF禁布计算。
- 两套DC/DC远离天线与相机时钟；SW/L1/L2高di/dt回路最短，反馈取样从输出电容安静端回到器件模拟地。
- DRV8833 PowerPAD、散热铜和导热过孔必须按官方尺寸设计。过孔填塞/阻焊/焊膏窗口需要板厂DFM确认，不能随意用大通孔吸走焊锡。
- 电机VM/OUT、地回流走线/过孔按测得电流、温升和铜厚计算，不在未布线时假报“2A额定PCB”。电源口和电机口靠边，留线束弯曲空间。
- 相机并口短且连续参考地；如需线束，先确定长度与返回路径，不假设任意长杜邦线也稳定。
- 同一元件位号在原理图、PCB、BOM和CPL中一致；PCB 1脚/极性丝印清楚、接口防呆。
