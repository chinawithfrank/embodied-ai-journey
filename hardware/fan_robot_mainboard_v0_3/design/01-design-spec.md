# V0.3 电气与 PCB 设计规格

## 已确定输入

专用一体主板，60×50mm、双层，三节 1.5V 干电池串联；两台 N20，用户确认 6V/60rpm；外接 2×9、2.54mm×2.54mm 相机；两线 5V 风扇按约 0.1A 原型负载预算设计，实际启动电流待实测。相机图纸板宽 24mm。电机电流和标签转速的测试条件没有资料，未捏造厂家参数。

## 电源

J1(BAT_RAW) → F1 → BAT_FUSED → Q2 反接保护 → BAT_PROTECTED → Q3 高侧开关 → VBAT。

Q2 AO3401A：D=BAT_FUSED，S=BAT_PROTECTED，栅极经 R1 下拉。Q3 AO3401A：S=BAT_PROTECTED，D=VBAT，R29 将栅极拉到源极默认关闭，SW1 只将栅极拉地开启，开关触点不承载电机电流。F1 为 MF-MSMF200-2，2A hold/4A trip、8V；有温度和时间特性，不是 2A 精密限流器。

VBAT 直接供 DRV8833，不增加 6V 升压。三节电池标称 4.5V，75% PWM 和桥路压降会进一步影响电机力矩/速度。此接法延用已工作原型，不据 6V/60rpm 标签承诺本机实际转速。

VBAT 经 D2、USB 限流输出经 D3 二极管 OR 到 VLOGIC_IN，再经 U2 TPS63802 升降压至 3.3V。USB 输入 U8 TPS2553DBVR，68.1k/1% 设定电阻，按原厂最大限流公式计算小于 500mA；没有 USB 电流协商，不据此声称符合所有主机枚举/取流要求。USB 不接电机/风扇电源，不给干电池充电。USB 单独供电只用于下载/有限负载逻辑调试，完整机器人用电池。

U2 反馈 560k/100k，L1 为 TI 推荐的 Murata DFE201612E-R47M=P2、0.47µH，Isat 5.5A、DCR≤26mΩ。MODE 接地。EN 分压 180k/100k 对应 VLOGIC_IN 名义约 3.08V 上升/2.80V 下降，不能直接当作电池欠压阈值。PG 接 ESP_EN、10k 上拉和 1µF 延迟，按首板测试确认掉压复位。

U3 TPS61023 由 VBAT 升到约 5V，反馈 732k/100k、L2 Wurth 74438357010、1µH，Isat 9.6A，DCR≤13.5mΩ。ACT_EN 控制升压 EN；不将“EN 关闭”写成输出隔离开关。Q1 AO3400A 低侧切换风扇黑线，D1 SS14 阴极接 FAN_5V、阳极接 FAN_SW。两线无刷风扇不是裸线圈，需测关断瞬态。没有风扇测速反馈。

C1 为 Panasonic 10SVPE220M / C165949，220µF/10V、6.3×5.9mm C6 聚合物电容，额定纹波 2.7Arms@100kHz/105°C、ESR≤20mΩ；按工作频率降额，不用普通低纹波铝电解直接替换。其推荐焊盘 gap2.1/overall9.1/height1.6mm。各 DC/DC 保留近端陶瓷去耦；22µF 0805 的容差/DC bias 纳入有效值预算，不能用 C1 替代近端 MLCC。

## 电机与硬件使能

DRV8833PWPR 为带 PowerPAD 的 HTSSOP-16；不得换成普通 PW 或不同引脚的 WQFN。VCP 至 VM 10nF，VINT 至地 2.2µF，VM 有近端去耦。RS1/RS2 为 0.39Ω/0.5W/1%，名义 Itrip≈0.2/0.39=0.513A；包含比较器容差，电机实际电流不等于这个名义值。保守限流是否足够起转，必须在样板和履带负载下验证。

ACT_EN = GPIO47(ACT_REQ) AND ESP_EN；ACT_REQ、ACT_EN 均外部下拉。ACT_EN 接 DRV8833 nSLEEP 和风扇升压 EN。FAN_GATE_LOGIC = GPIO40 AND ACT_EN，经 100Ω 驱动 Q1，栅源 100k 下拉。四路电机输入也有外部下拉；GPIO42 读取 3.3V 上拉的低有效 nFAULT。

GPIO47 未经程序主动使能、复位或刷写时，负载默认关闭。该电路不构成独立硬件看门狗：软件卡死且引脚一直为高时仍需 WDT/故障处理和物理电源开关。新板是否解决刷机自转，要在首板用示波器验收，不能由 DRC 推定已实测。

## 主控、接口和布线

ESP32-S3-WROOM-1-N16R8（16MB Flash/8MB Octal PSRAM）。GPIO35/36/37 不复用。电池检测改为 GPIO1/ADC1_CH0，1M/330k/100nF；AIN1 改为 GPIO15，避免 Wi-Fi 与 ADC2 的冲突。USB DM/DP 经 ESD/22Ω 接 GPIO19/20；BOOT/RESET 在背面。I2C41/48、UART43/44、复位/启动口为预留扩展。

实际层序：F.Cu 和 B.Cu，两个铜层同时承载信号与电源，并在剩余区域铺 GND。GND 和 VBAT 在双层上重新布线，不依赖旧四层版的内层平面；地铜岛剔除，必要处加接地过孔。不存在连续、专用的内层参考地，因此不能照搬四层版的阻抗或抗干扰结论。天线朝上边，全层 x6～54、y<6mm 禁铜；模组天线周围至少约 15mm 的结构金属净空需在整机安装时维持。

普通信号 0.20mm；主电池与 VBAT 主干 0.80mm；逻辑电源 0.50mm；电机/风扇主干 0.45mm，电机 IC 输出短扇出 0.20mm，B 通道采样短扇出 0.18mm，其他细引脚处允许短距离缩颈；GND 显式连接 0.30mm 加双面地铜。常规过孔 0.6/0.3mm，双面盖油。DRV 散热过孔位于焊膏窗口外；ESP32 导热孔 0.3mm，孔边至焊膏开口最小约 0.10mm，需按制造说明复核工艺。开关电源的局部热回路、反馈取样和 USB 局部走线保留人工指定路径，电机主回路及数字回流在首板复核。

USB 使用原生全速 USB（12Mbit/s），短距离走线主干 0.25mm。1.6mm 普通双层 FR4 并未实现受控 90Ω 差分阻抗，不给工厂下达已满足 90Ω 的错误承诺；首板验收包含 USB 稳定下载、反复插拔，以及相机/Wi-Fi/双电机并发时的图像、电源、USB 与温升测试。若信号完整性测试失败，需要重新设计，不能以 DRC 通过代替波形与功能验证。

## 首板功耗边界

3.3V 负载预算平均 0.5A、峰值 0.8A；风扇约 0.1A@5V；双电机限流各约 0.51A。在 VBAT=3.0V、效率按 85% 估算的峰值总电流可超过 2.2A，电池内阻/盒触点可能造成掉压。干电池能否同时支持相机/Wi-Fi/双电机启动需实测，不以稳压芯片额定电流替代电池能力。未承诺续航、60rpm、满负载连续额定或量产合格。
