# 第三个月：机器人视觉

> **本月方向：让机器人不只是“知道动作”，还开始从相机画面中理解眼前有什么。**

前两个月，我学习了 ROS2 怎样传递状态、MoveIt 怎样将目标变成安全轨迹。但一个真正的机器人不能总等人把物体的坐标填进表单：它首先要看见物体，才能决定要抓什么、去哪里抓。

这个月从最小但完整的视觉闭环开始：**取一帧图像 → 找到物体 → 输出它在图像中的位置 → 把结果交给后续机器人模块。** 网球是第一个对象，因为它外观清楚、尺寸固定、也很容易在镜头前做重复实验。

## 本月学习地图

### 已开始：用 YOLO 看见一颗网球

[01 · YOLO 网球识别与像素坐标](01-YOLO-Tennis-Ball) 下载公开标注数据训练单类别检测器；在摄像头画面上画出框、置信度和中心点 `(u, v)`，并可选发布 ROS2 话题。

## 一个重要边界

第一节输出的是**像素坐标**，例如 `(u=534, v=287)`。这回答“网球在这张图的哪里”，还没有回答“网球离机器人多远”。后者需要相机内参、深度信息或多视角三角化，是本月后续实验要解决的问题。
