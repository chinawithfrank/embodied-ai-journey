# 风扇机器人：从看见到行动

> 这次不只让屏幕里的机器人动起来。我想做一台能够看见目标、移动、用风影响物体的小机器人。

项目的起点是一块已有的 ESP32 开发板。讨论硬件时，我逐渐明确了真正想做的东西：它不只是一个遥控风扇，而是可以朝我的手吹风，或者发现地上的气球、调整位置，把气球吹向指定区域的机器人。

最终我希望在同一台机器上比较两种控制方式：一种是我写下的规则，另一种是通过反复交互训练出的策略。不过在那之前，有一件不能跳过的小事：**先让它稳定地看见。** 没有可靠画面，后面所谓“策略不够聪明”，可能只是摄像头掉线了。

## 后续路线，不是当前已实现功能

1. 看见：确认取流、清晰度、延迟和断连表现。
2. 看懂：先做离线手部检测，输出图像位置，明确像素不等于距离；之后再考虑气球。
3. 行动：遥控移动和吹风，加入急停、断联停车。
4. 闭环：根据画面调整位置，用规则控制建立基准。
5. 学习：定义观察、动作、奖励和复位，先做简化仿真，再与实物对照。

ESP32 负责采集和底层执行；电脑承担更重的识别与训练。项目不会因为用了一个神经网络就自动成为可靠的机器人，每一层都要有自己的验收方法。
