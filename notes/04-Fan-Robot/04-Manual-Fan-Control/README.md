# 让风真正成为一个动作：保留相机和轮子，加上风扇开关

前一节不是简单地“把电机插上”：A路40%、60%都不能起动，100%诊断能转，随后80%普通PWM也能转。这些结果让我能区分“网页有指令”和“硬件真的在行动”。B路、双电机供电和干扰仍要分别验收，不能把一台成功当成整车完成。

现在加上已有的LR7843模块和5V小风扇。第一步不追求调速或自动追踪，只验证一个新动作：**相机继续看，轮子仍能点动，风扇能独立开关并可靠撤销输出。**

## 1. 先分清：开关模块不是电源

LR7843是功率MOSFET的型号，成品模块还可能带光耦、上拉和其他驱动电路。芯片资料不能证明某块模块的端子定义、支持3.3V输入、在5V负载供电下能完全导通或具有什么保护。芯片的阈值电压也不等于满负载导通电压。[Infineon芯片资料](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irlr7843-datasheet-en.pdf)

2026-10-30，用户补充实物照片：风扇为 **Delta AFB0405MA-A，标签DC5V、0.10A，红黑两根电源线**；模块正面可见LR7843和PC817，背面信号端为 `PWM/GND`，负载端为 `+/LOAD/-`。这些照片确认了型号和丝印，但没有证明成品模块的最低工作电压、逻辑输入指标或已经接线验收。风扇配置仍默认禁用，不自动创建启用文件。

- 核对模块支持 **3.3V逻辑控制**，并能在本次 **约4.5V负载电源** 下工作。照片中的PC817不能单独证明这一点。若模块说明只支持6～28V，不为迁就模块给5V风扇加6V或12V，应换适配低压的开关方案。
- 本次实物已确认是两线无刷风扇，只控制电源开关；此版本不读取转速，也不驱动四线PWM调速脚。**不要像前面的N20一样交换红黑线试反转，风扇极性接反可能损坏内部电路。**
- Delta的AFB0405MA-A系列资料给出工作电压4.5～5.5V；完整订货后缀和实物来源未进一步核验，参数仅作对应系列参考。三节电池标称4.5V已处于下限，电池老化、触点压降和两个电机启动都可能使风扇端电压低于范围。可先做短时实验，不承诺整机稳定运行。[Delta规格资料](https://www.delta-fan.com/Download/Spec/AFB0405MA-AF00.pdf)
- 不从ESP32 GPIO或3V3给风扇供电；本轮也不从开发板5V排针给它带载。LR7843只负责开关，不升压、不稳压。
- 用户选择原三节干电池同时供电机和风扇：从开关后的电池输出**并联分支**到DRV8833与LR7843，不串联两种负载。ESP32和相机仍用原USB，不在本轮改成电池给ESP32供电。先确认风扇直连可起动，再检查模块开关和联合运行；若需要独立对照电源，可用固定稳压5V成品电源，不用未经测量的可调模块。
- 若模块没有负载尖峰抑制、风扇有特殊断电保护要求，应按实际器件说明补齐；不把MOSFET的体二极管当成所有负载都已获保护。

## 2. 不动旧线，只增加一路候选GPIO

| 功能 | 当前配置 |
|---|---|
| 相机 | 原GPIO4～14、16～18、21，板载24MHz时钟，无外接XCLK |
| 电机IN1/2/3/4 | 原GPIO1/2/38/39 |
| USB | GPIO19/20保留 |
| 风扇开关控制 | 候选GPIO40，默认未启用 |

若电机本地配置已经把SLEEP接到GPIO40，**不能共用**。新固件会检查风扇引脚与相机、电机输入、可选SLEEP/FAULT、USB及保留脚冲突，冲突时只禁用风扇，不去改旧配置。也要检查自己后来加的其他外设。

按本次背面丝印，下图给出共用电池的接线关系；这是对高电平开启低侧开关的测试接法，**仍需确认模块在4.5V下的驱动与3.3V输入兼容性**。不要仅凭芯片型号宣称兼容已验收，也不要按翻转照片后左右位置接：

```text
电池开关后正极 ──┬── 原DRV8833 VCC（保持）
                 ├── LR7843「+」
                 └── 风扇红线
风扇黑线 ─────────── LR7843「LOAD」
电池负极 ────────┬── LR7843「-」
                 └── 原DRV8833 GND（原ESP32共地保持）

ESP32 GPIO40 ─────── 模块控制输入（如 IN / PWM）
ESP32 GND ────────── 模块控制输入地（如信号 GND）
```

**LOAD不是电源负极。** 如果风扇负线直接接电源负极，会绕开开关而一直转。若实际模块端子不同、有单独控制VCC或采用不同电路，先取得对应接法，不照此图猜。

原ESP32与DRV8833已经共地，本轮又共用电池，因此整机中信号地与负载地已有外部连接，不能再声称完全电气隔离。电机/风扇电流应直接返回电池负极，不绕经ESP32的地线或细面包板通路。LR7843信号GND接ESP32 GND，不能把开关串到原ESP32或DRV8833的地线中。以后使用独立电源时，是否分地仍以模块实际电路为准，不能只看“隔离”商品标题。

高电平开启的控制输入，应按模块要求增加合适的默认关断偏置，例如在确认输入兼容后将信号端用10kΩ下拉到信号GND。软件内部下拉是在初始化后才配置，不能保证上电、复位、刷写期间的输入状态。主动低电平模块需要相反的偏置；不能把模块的5V上拉直接接ESP32 GPIO。

所有改线均先关闭电池开关、拔掉ESP32 USB；若另接了测试电源也一起断开。风扇固定并装防护罩，导线远离叶片；不捏叶片做堵转试验。相机线、电机控制线都保留。

### 先不接模块，验证这组电池能否带动风扇

断电后先暂时断开并绝缘DRV8833的VCC供电线，避免本轮误操作电机。固定风扇，红线接电池正输出，黑线接负输出，开启开关约1秒后关闭。能起动才继续试开关模块；不转或只抖动就停，不换成6V/12V，也不把反接当作排错手段。没有万用表时，这只能确认“这次能起动”，不能确认电压余量或长期供电能力。

然后再次断电，撤掉直连试验线，改按上图接模块。尤其不能保留风扇黑线直达电池负极的旁路线。首次只测风扇，电机VCC先不恢复；开关正常、上电不自转后，再断电恢复DRV8833供电并联合测试。若直连能转、经过LR7843不转，不急着改程序：模块低压驱动不足、控制电平不兼容或接线问题都需要排查。

## 3. 一个新草图，复用原配置

新入口：[`esp32_fan_manual.ino`](../../../ros_ws/src/fan_robot/firmware/esp32_fan_manual/esp32_fan_manual.ino)。它在一块ESP32里组合：

- 原相机：80端口网页、`/health`、`/capture`，81端口MJPEG。
- 原电机：82端口原API、10～100%滑块（仍默认20%）、点动和诊断。
- 新风扇：同一个82端口页面内的独立开关和 `/api/fan/*`，不再开第四个HTTP服务。

相机配置仍从 `esp32_camera/camera_config.local.h` 读取；电机配置仍从 `esp32_motor_manual/motor_config.local.h` 读取，**不要再复制一份或覆盖原文件**。风扇只用普通数字GPIO，不分配LEDC定时器或通道，不改变电机20kHz PWM和相机时钟。

旧相机草图、旧电机草图仍保留，可重新上传退回对应实验。“不影响旧功能”指保留接线与软件接口，不保证未经实测的供电抗干扰。一个ESP32一次只运行一个固件；这个Arduino组合版没有集成此前ESP-IDF的离线手部模型，也不会自动跟随或自主吹风。

### 先编译默认禁用版

Arduino IDE打开新入口，保持原来已验证的设置：ESP32S3 Dev Module、16MB Flash、OPI PSRAM、Hardware CDC and JTAG、USB CDC On Boot Enabled，沿用原生非TTL的USB口。保持整个仓库目录结构，不把单个ino拷出去。

**风扇和电机电源均关闭后上传。** 相机和电机的私有配置照常生效；风扇显示 `fan_wiring_not_confirmed`，不会配置GPIO40。先检查视频和原电机按钮仍在，不需要 `colcon build` 或电脑服务器。

### 确认模块与接线后再启用

将新目录中的 `fan_config.example.h` 复制为同目录的 `fan_config.local.h`：

```cpp
#pragma once

namespace fan_settings {
constexpr bool wiring_confirmed = true;
constexpr int control_pin = 40;
constexpr bool active_high = true;
}
```

只有确认模块兼容电源/逻辑、电源极性、端子和偏置后，才将 `wiring_confirmed` 改成true。`active_high` 是模块控制逻辑，不是让风扇默认启动；不确定时不要随意切换来试错。该本地文件被Git忽略，本次没有替用户创建或启用它。

关闭电机与风扇电源，再编译上传；刷新网页不会更新固件。开发者可从仓库根目录构建：

```bash
arduino-cli compile \
  --fqbn 'esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,CDCOnBoot=cdc,USBMode=hwcdc,PartitionScheme=fatflash' \
  ros_ws/src/fan_robot/firmware/esp32_fan_manual
```

## 4. 在同一个网页让轮子与风扇各做各的

连接原热点 `FanRobot-Camera`，默认密码 `fanrobot123`；若原配置使用其他热点或STA地址，沿用实际地址。打开 [82端口组合控制页](http://192.168.4.1:82/)，下方新增“独立风扇开关”。

1. 因为共用电池，要只测风扇时，在断电状态暂时断开DRV8833的VCC供电支路，而不是指望同一个总开关只关电机。接通电池后风扇应不转。若一上电就转，立即关电池，检查模块逻辑、LOAD旁路线及关断偏置，不用手阻挡叶片。
2. 点击“解锁并开启风扇”，观察输出开启；点击“关闭风扇”，确认撤销输出。**`running`只表示提交给模块的逻辑输出，不是转速反馈。** 实际叶片会有惯性。
3. 再次开启，检查30秒上限、切后台或关闭页面后停止、断开热点后停止；重新连接或回到页面不会自动恢复。确认可撤销输出后再增加其他负载。
4. 风扇单测通过后，断电恢复DRV8833的VCC，电机架空，重新接通电池，手动选已验证的80%：先分别短点动A/B，再两台一起。最后开启风扇并在同页点动电机；电机松手停止不改变风扇租期，关闭风扇也不改变电机指令。若单独可转、共同不起动，优先检查供电承载与压降，不当作PWM必然失效。
5. 顶部组合提示条有“停止电机和风扇”，同时请求两个子系统停机。电机区域原来的“停止并锁定”只针对电机，“关闭风扇”只针对风扇。物理电源开关仍须可触及。
6. 最后只打开一个相机视频查看器，观察各负载启动时有无复位、掉线或花屏。出现异常先断负载电源检查，不提高电压、取消超时或改相机线来掩盖问题。

风扇的开启按钮在内部先获取新会话，再发送带递增序号的运行心跳；收到回应后约200ms发送下一次。独立任务约20ms检查一次：约1秒收不到有效心跳就撤销输出，单次运行最多30秒，心跳不能无限续期；只解锁不运行则5秒后失效。旧会话、重复序号、停止后的迟到请求不能重新开启。

这些时限是软件保护，不是硬件紧急停止或精准机械停止承诺。网络、任务调度、MOSFET失效、输入偏置和叶片惯性都可能影响实物表现。会话号也不是身份认证：只在可信热点/局域网单人调试，不做公网映射。

## 5. 代码和排错入口

| 文件/状态 | 含义 |
|---|---|
| `fan_guard.hpp` | 不依赖硬件的会话、心跳、30秒运行限时和停止逻辑 |
| `fan_server.hpp` | 引脚冲突校验、数字输出、独立任务和82端口扩展注册 |
| `fan_page.hpp` | 复用原电机页，追加独立风扇控件和全部停止 |
| `/api/fan/status` | `ready`为软件路径就绪，`running`为逻辑输出；不是风扇测速或供电测量 |
| `fan_wiring_not_confirmed` | 默认保护，尚未确认本地接线配置 |
| `invalid_or_conflicting_fan_gpio` | 引脚不可输出，或与相机/电机/USB/保留脚冲突 |
| `heartbeat_timeout` / `run_timeout` | 心跳中断或达到30秒上限，需要再次主动开启 |
| `fan_gpio_error` / `fan_watchdog_failed` | 输出/停机任务异常，禁用风扇，不取消保护继续试 |

风扇API是 `GET /api/fan/status`，以及JSON的 `POST /api/fan/arm`、`run`、`stop`；arm/stop只接受空对象，run只接受当前 `session` 和递增 `sequence`。非法请求会锁定风扇，不改变电机状态。新增功能不改原电机API的字段。

## 验收记录

2026-10-30开始实现，随后已收到LR7843正反面和Delta两线风扇照片，记录用户选择共用4.5V电池。端子/标签已识别，不等于模块低压兼容和联合运行已验收；本次未启用风扇私有配置、未改固件。编译、主机测试和实际吹风是三件不同的事：先核对模块，再逐项记录直连起动、上电不转、开/关、30秒限时、断联停、复位不自启、联合负载和视频稳定性。

同日使用Arduino-ESP32 3.3.12完整构建通过：原相机入口982,811字节、原电机入口1,009,694字节、新组合版默认禁用风扇1,015,690字节；另以临时编译配置启用GPIO40，构建1,016,430字节，组合版静态RAM56,764字节。临时启用头文件在工作区外，验证后移除；未创建 `fan_config.local.h`，未修改原相机/电机私有配置，也没有刷写设备。

18项主机测试通过：除原相机、电机、手部观测测试外，新增风扇上电关闭、闲置解锁过期、心跳超时、30秒上限、旧会话/重复序号拒绝、提前停止、计时器回绕和电机逻辑独立性；网页模拟覆盖无自动开启、心跳、独立/全部停止、迟到解锁响应和超时后不自动续开。文档本地链接和差异空白检查通过。这些是软件检查，不是风扇转速、电流、模块电平或联合稳定性的测量。
