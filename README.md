# 从零打造具身智能机器人

> 记录我从零开始打造真实世界 AI 机器人的旅程。

一个软件工程师踏入具身智能的旅程。

我花了很多年时间构建软件系统。
现在，我在学习如何打造能在物理世界中
感知、思考、行动的机器。

这个仓库正在记录了我的整个学习历程：
从 ROS2 基础 → 机器人仿真 → 感知 → AI 智能体 → 真实机器人 →

一切都是开源的。
一切都是一步步搭建起来的。

⭐ 如果你也在探索具身智能，欢迎 Star 这个仓库。

---

## 旅程地图

```
软件工程师 ──► ROS2 基础 ──► 仿真 ──► 感知 ──► AI 智能体 ──► 真实机器人
```

每一章都遵循同一个循环：**学习 → 构建 → 分享（Learn → Build → Share）**。
我遇到一个真实问题，学习背后的原理，动手搭建一个小东西来验证自己真的理解了，
然后原原本本地分享一路踩过的坑。
